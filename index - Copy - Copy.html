🚀 B.E. Project 2024

Smart Parking System Using Sensors

🏛️ Adhichunchangiri Institute of Technology, Chikkamagaluru

Designed and built a fully functional IoT-enabled smart parking management system as part of my B.E. engineering coursework. The system employs ultrasonic sensors and IR (infrared) sensors mounted at each parking slot to detect whether a vehicle is present in real time.

The occupancy data is aggregated by an Arduino microcontroller, which drives a 16×2 LCD display showing the number of free and occupied slots. A web-based dashboard was also prototyped to allow remote monitoring of parking slot status, bridging embedded hardware with software interfaces.

Key Features

  • ⚡ Real-time slot detection using HC-SR04 ultrasonic sensors
  • 📡 IR sensors as a redundant occupancy check layer
  • 🖥️ Live LCD display showing available / total slots
  • 🌐 Prototype web dashboard for remote monitoring
  • 🔋 Low power consumption embedded design
Arduino Uno HC-SR04 IR Sensors 16×2 LCD Embedded C IoT

☕ Java 2023

Bank Account Management System

🏛️ Academic Project — B.E. Computer Science

A comprehensive, console-based banking application built entirely in Java to demonstrate mastery of Object-Oriented Programming principles. The system models real banking operations — account creation, deposits, withdrawals, and transaction history — using a class hierarchy rooted in an abstract BankAccount base class.

The design applies all four OOP pillars: encapsulation (private fields with getters/setters), inheritance (SavingsAccount and CurrentAccount extending BankAccount), polymorphism (overridden calculateInterest() methods), and abstraction (interfaces for Transferable and Auditable operations).

Key Features

  • ☕ Abstract class + interface-based architecture
  • 🏗️ Inheritance: Savings, Current, and Fixed Deposit accounts
  • 🔄 Polymorphic interest calculation per account type
  • 📋 Full transaction history with formatted console output
  • 🔐 Input validation and exception handling
Java OOP Inheritance Interfaces Exception Handling

A modular collection of Python scripts built to automate repetitive daily workflows. The project covers a range of real-world automation scenarios — from organising a chaotic downloads folder to pulling live data from public APIs and generating formatted PDF reports automatically.
